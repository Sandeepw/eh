Sgut down the VM. Attach an additional hard disk of 20GB to the Virtual machine. Power on the virtual machine. 

Install cryptsetup if it is not installed.

For Ubuntu
apt install cryptsetup

For CentOS/Rocky 

dnf install cryptsetup

Verify installation with 
cryptsetup -h or cryptsetup --help

Now find out the hard disk device name using
lsblk

Create a partition on the hard disk using 
fdisk  hard-disk-device-name

Check the partition name using 
lsblk

Format the partition using cryptsetup
cryptsetup luksFormat hard-disk-partition

it will prompt for the passphrase(password)

Remember this password as each time you want to mount this device the tool will prompt you for this password.

Once the format finishes, you have to create a mapper device for this partition.

cryptsetup luksOpen hard-disk-partition any-name

One the command finishes, check with 
lsblk
also with
ls /dev/mapper 
This should display an entry by the name that you specified in the above command.

Now you have to format the mapper device with the Linux file system. Here ext4 file system is deployed.

mkfs.ext4  /dev/mapper/any-name(given above)

To mount this device create a mount point (directory).

mkdir /mnt/cipher-data

Now mount the device

mount /dev/mapper/any-name /mnt/cipher-data

Now go to the directory 
cd /mnt/cipher-data

Now you can create directories and files inside this.

Once you are done with accessing or creating the data then for safety reasons you can close the device.

Come of the directory
Then unmount the mapper device.

umount /dev/mapper/any-name

Now close the device.
cryptsetup luksClose /dev/mapper/any-name

You can check the properties of the device using
cryptsetup luksDump device-name

To mount the device again using following steps

cryptsetup luksOpen hard-disk-partition anyname

Then
Mount it.
